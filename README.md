# PFO1 - Landing Page Portafolio Personal

## Descripción
Proyecto correspondiente a la **Práctica Formativa Obligatoria 1 (PFO1)**. Consiste en una landing page de portafolio personal desarrollada desde cero con HTML5 semántico y CSS3 puro, estructurada bajo estándares web modernos y diseño completamente adaptable (responsive design).

---

## 🔗 Despliegue en Producción
- **URL en Vercel:** [ifts-front-end.vercel.app](https://ifts-front-end.vercel.app/)
- **Repositorio Público:** [github.com/Damian-E/ifts_frontEnd](https://github.com/Damian-E/ifts_frontEnd)

---

## 🛠️ Tecnologías y Requisitos Técnicos Aplicados
- **HTML5 Semántico:** Uso riguroso de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
- **CSS3:** Sistema de variables CSS, layout con Flexbox y CSS Grid.
- **Tipografía:** Integración de Google Fonts (*Poppins*).
- **Diseño Responsive:** Breakpoints mediante Media Queries para móviles, tablets y desktop.
- **Interactividad & Accesibilidad:** Animación flotante `@keyframes` en la imagen principal, transiciones `:hover`, atributos `alt` descriptivos en todas las imágenes y etiquetas `<label>` vinculadas a sus respectivos `input`/`textarea`.
- **Integración con GitHub:** Enlaces visibles y directos al perfil del autor.

---

## 🎨 Decisiones de Diseño
- **Paleta de Colores:** Fondo oscuro (*Dark Mode*) con tonos azul/slate para una estética moderna y profesional propia del entorno tech.
- **Jerarquía Visual:** Uso de cards con efectos hover para destacar habilidades e intereses de forma intuitiva y limpia.
- **Sección Personal:** Inclusión de un bloque enfocado en el interés por el desarrollo de software y la automatización de finanzas personales.
